## Подробное описание

### Расчет базовых параметров и комплексных чисел
В первой части работы выполнена инициализация среды и проведены базовые вычисления по индивидуальному варианту:
* Номер студента в списке группы принят равным a = 24, общее количество студентов в группе принято равным b = 26.
* Найдена разность c = b - a = 2 и вычислена вспомогательная константа d = c * b - a = 2 * 26 - 24 = 28.
* Сформировано комплексное число e = a + 1i*b = 24 + 26i, где 1i задает мнимую единицу.
* Рассчитано масштабированное значение h = d * pow2(10, 2) = d * 10^2 и значение g = a * pi.
* Состояние рабочей области сохранено в файл lab1_part1.mat для использования в последующих секциях.

### Векторные операции и линейные массивы
Во второй части исследованы базовые операции векторной алгебры:
* Из файла lab1_part1.mat загружены переменные c и d. Длина массивов определена как N = c + 1 = 3.
* Созданы нулевые вектор-строки f и g размерности 1xN с помощью функции zeros(1, N).
* Выполнено поэлементное сложение векторов h = f + g и масштабирование полученного результата на константу j = d * h.
* Сформирован единичный вектор-столбец v размерности Nx1 с помощью ones(N, 1). Выполнено обращение к третьему элементу v(3) с выводом значения в командное окно.
* Рабочая область экспортирована в lab1_part2.mat.

### Матричные вычисления и выборка данных
В третьей части исследованы матричные операции над двумерными массивами:
* Созданы квадратные матрицы A (нулевая матрица 3x3) и B (единичная матрица 3x3).
* Вычислено матричное произведение C = A * B и поэлементное произведение D = A .* B.
* Продемонстрирована адресация элементов матрицы: извлечен угловой элемент D(1,1), второй столбец D(:,2) и вторая строка D(2,:).
* Данные сохранены в файл lab1_part3.mat.

### Циклические конструкции и условные операторы
В четвертой части реализованы типовые алгоритмические структуры управления потоком вычислений:
* Реализован цикл for с параметром c от 1 до 10*a (до 240) для вычисления суммы ряда натуральных чисел.
* Реализован цикл for с вложенной проверкой mod(c, 2) ~= 0, обеспечивающий накопление суммы только для нечетных значений ряда.
* Сформирован цикл while x < a с шагом инкремента x = x + 1, производящий суммирование отсчетов до достижения верхней границы a.
* Результаты сохранены в файл lab1_part4.mat.

### Статистические функции и вспомогательные векторы
В пятой части выполнено исследование функций статистической обработки данных:
* Сгенерирован вектор нормально распределенных псевдослучайных чисел A размерности 1x10 с помощью randn(1, 10).
* Определены минимальный элемент minA = min(A), максимальный элемент maxA и его порядковый индекс maxAind через множественный возврат [maxA, maxAind] = max(A).
* Сформированы единичный вектор C = ones(1, 10) и нулевой вектор D = zeros(1, 10).
* Состояние переменных сохранено в lab1_part5.mat.

### Построение комплексных графиков и экспорт результатов
В шестой части отработаны методы визуализации числовых массивов:
* Сгенерирован вектор случайных данных A из 100 отсчетов с нормальным распределением.
* С помощью команды figure открыто графическое окно, где в единых осях через hold on объединены: гистограмма bar, график дискретных отсчетов stem и линейный график plot.
* Подписаны оси координат (ось х - отсчеты, ось у - амплитуда), добавлен заголовок «Случайный вектор», включена сетка grid on и настроена легенда legend.
* Установлены границы отображения: по оси абсцисс от 1 до 90 через xlim([1, 90]), по оси ординат от минимального до максимального значения вектора через ylim([min(A), max(A)]).
* График экспортирован в растровый файл graphic.jpg вызовом exportgraphics, а рабочая область сохранена в lab1_part6.mat.

## Технические примеры

### Вычисление скалярных констант и сохранение рабочей области (lab1.m)
Инициализация параметров варианта и расчет базовых величин:

```matlab
clear all;
a = 24; b = 26;
c = b - a;
d = c.*b - a;
e = a + 1i*b;
h = d .* pow2(10,2);
g = a * pi;
save("lab1_part1.mat");
```

### Векторно-матричные операции и адресация (lab1.m)
Поэлементные и матричные операции над массивами:

```matlab
clear all;
load("lab1_part1.mat",'c','d');
N = c + 1;
f = zeros(1,N); g = zeros(1,N);
h = f + g;
j = h * d;

v(3)

A = zeros(3,3); B = ones(3,3);
C = A * B;

D(1,1)
D(:,2)

```

### Алгоритмические циклы for и while (lab1.m)
Реализация накопительного суммирования и фильтрации четных чисел:

```matlab
clear all;
load("lab1_part1.mat","a");
cntr = 0;
for c=1:10*a
    cntr = cntr + c;
end

cntr2 = 0;
for c=1:10*a
    if mod(c,2) ~= 0
        cntr2 = cntr2 + c;
    end
end

cntr3 = 0;
x = 0;
while x<a
   cntr3 = cntr3 + x;
   x = x+1;
end
save("lab1_part4.mat");
```

### Статистические расчеты и построение графика (lab1.m)
Определение характеристик вектора и многокомпонентная визуализация:

```matlab
clear all;
A = randn(1,10);
[maxA, maxAind] = max(A); minA = min(A);
C = ones(1,10);
D = zeros(1,10);
save("lab1_part5.mat");

clear all;
A = randn(1,100);
figure;
bar(1:100,A,'FaceColor',[0.2 0.7 0.2]);
hold on;
stem(1:100,A,'Color','blue');
hold on;
plot(1:100,A,'Color','red');
xlabel('ось х - отсчеты');
ylabel('ось у - амплитуда');
title('Случайный вектор');
legend('Гистограмма (bar)','Отсчеты (stem)','Линейный график (plot)');
xlim([1,90]);
ylim([min(A), max(A)]);
grid on;
exportgraphics(gcf,'graphic.jpg');
save("lab1_part6.mat");
```
