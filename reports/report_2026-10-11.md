## Подробное описание

### Формирование гармонических колебаний заданной частоты
В первом и втором пунктах работы исследовано дискретное представление гармонических функций:
* Задан начальный шаг дискретизации SS = 0.1 с. На интервале времени от 0 до 2*pi сгенерирован один период синусоидального колебания y = sin(samples) и построен его временной график.
* В соответствии с вариантом задания введен параметр частоты f = 5. Сформирован сигнал y = sin(f * samples) с тем же шагом дискретизации. На интервале [0, 2*pi] укладывается ровно 5 полных периодов колебания.

### Формы визуализации и спектральное разложение
В третьем и четвертом пунктах сопоставлены способы графического вывода и выполнен спектральный анализ:
* В многооконном режиме subplot(2, 2, ...) выведены: непрерывная линия plot, импульсные отсчеты stem и ступенчатая диаграмма stairs.
* С помощью функции fft рассчитано прямое быстрое преобразование Фурье. Для получения амплитудного спектра вычислен модуль комплексных коэффициентов spectrum = abs(fft(y)).
* Построена ось частот freqs = f * samples. График подтвердил наличие выраженного спектрального пика на частоте f = 5 рад/с.

### Аддитивный белый гауссов шум и зашумленный канал
В пятом и шестом пунктах смоделирован канал связи с шумом:
* Для детального представления сигналов и случайных флуктуаций шаг сетки уменьшен до 0.001 с на отрезке [0, 2*pi].
* С помощью встроенной функции wgn(1, length(samples), -10) сгенерирован аддитивный белый гауссов шум мощностью N = -10 дБВт.
* Шум наложен на синусоиду операцией векторного сложения signal = y + noise. Построен временной график сигнала с шумом и рассчитан его амплитудный спектр abs(fft(signal)), на котором наглядно виден подъем шумовой полки во всей полосе частот.

### Фильтрация зашумленного сигнала скользящим средним
В седьмом и восьмом пунктах реализован сглаживающий фильтр:
* В соответствии с разностным уравнением скользящего среднего с длиной окна Len = 3 заданы коэффициенты: числитель b = (1/Len) * ones(1, Len), знаменатель a = 1.
* Выполнена цифровая фильтрация массива функцией filter(b, a, signal).
* Построен график отфильтрованного сигнала и его спектр spectrum3 = abs(fft(filtered)). Сравнение со спектром зашумленного сигнала подтвердило значительное ослабление высокочастотных шумовых компонент.

### Перенос на несущую частоту и когерентное детектирование
В пунктах 9-11 реализована процедура модуляции:
* Сформирован сигнал несущей частоты carry = sin(10*f*samples) с частотой 10*f = 50 рад/с той же длины, что и информационный сигнал.
* Модуляция осуществлена путем поэлементного перемножения carried = y .* carry. Построен совмещенный график модулированного и исходного информационного сигналов.
* К модулированному колебанию добавлен вектор шума: noised_carried = carried + noise. Построен график зашумленного модулированного сигнала и его спектр spectrum4 = abs(fft(noised_carried)).

### Выделение информационного сигнала фильтром Баттерворта
В пунктах 12-13 осуществлен прием и восстановление переданного сообщения:
* Выполнено синхронное детектирование: зашумленный модулированный сигнал умножен на опорное несущее колебание NoCarry = noised_carried .* carry. В результате переноса спектра получены низкочастотная информационная компонента и высокочастотная составляющая на удвоенной частоте несущей.
* Рассчитаны коэффициенты аналогового прототипа цифрового низкочастотного фильтра Баттерворта 4-го порядка с нормированной частотой среза 0.008 с помощью функции [b_butter, a_butter] = butter(4, 0.008, 'low').
* Для фильтрации без фазовых искажений применена функция двунаправленной фильтрации filtfilt с множителем 2: FillNoCar = 2 * filtfilt(b_butter, a_butter, NoCarry). Это позволило подавить компоненты удвоенной несущей и восстановить форму исходной синусоиды.
* Результирующий график экспортирован в graphic_lab2.jpg.

## Технические примеры

### Генерация гармонического сигнала и расчет спектра БПФ (lab2.m)
Формирование синусоиды с частотой f = 5 и спектральное разложение:

```matlab
clear all;
close all;
SS = 0.1;
samples = 0:SS:2*pi;
f = 5;
y = sin(f * samples);

figure('Name', 'Части 2-4: Сигнал частоты f и формы отображения');
subplot(2, 2, 1);
plot(samples, y);
xlabel('Время t, с');
ylabel('Амплитуда');
title('Непрерывный график (plot)');
grid on;

subplot(2, 2, 2);
stem(samples, y, 'filled');
xlabel('Время t, с');
ylabel('Амплитуда');
title('Дискретные отсчеты (stem)');
grid on;

subplot(2, 2, 3);
stairs(samples, y);
xlabel('Время t, с');
ylabel('Амплитуда');
title('Ступенчатый график (stairs)');
grid on;

freqs = f * samples;
spectrum = abs(fft(y));
subplot(2, 2, 4);
plot(freqs, spectrum, 'r');
xlabel('Частота \omega, рад/с');
ylabel('Амплитуда');
title('Амплитудный спектр (БПФ/FFT)');
grid on;
```

### Наложение шума и фильтрация скользящим средним (lab2.m)
Формирование белого гауссова шума и сглаживание КИХ-фильтром:

```matlab
samples = 0:0.001:2*pi;
freqs = f * samples;
y = sin(f * samples);
noise = wgn(1, length(samples), -10);
signal = y + noise;

Len = 3;
a = 1;
b = (1 / Len) * ones(1, Len);
filtered = filter(b, a, signal);

figure('Name', 'Части 5-8: Шум и фильтрация скользящим средним');
subplot(2, 2, 1);
plot(samples, signal);
xlabel('Время t, с');
ylabel('Амплитуда');
title('Зашумленный сигнал (WGN, -10 дБВт)');
grid on;

spectrum2 = abs(fft(signal));
subplot(2, 2, 2);
plot(freqs, spectrum2);
xlabel('Частота \omega, рад/с');
ylabel('Амплитуда');
title('Спектр зашумленного сигнала');
grid on;

subplot(2, 2, 3);
plot(samples, filtered);
xlabel('Время t, с');
ylabel('Амплитуда');
title(sprintf('Отфильтрованный сигнал (L = %d)', Len));
grid on;

spectrum3 = abs(fft(filtered));
subplot(2, 2, 4);
plot(freqs, spectrum3);
xlabel('Частота \omega, рад/с');
ylabel('Амплитуда');
title('Спектр после скользящего среднего');
grid on;
```

### Модуляция на несущую частоту (lab2.m)
Перенос спектра полезного сигнала на частоту 10*f = 50 рад/с:

```matlab
carry = sin(10 * f * samples);
carried = y .* carry;

figure('Name', 'Часть 9: Модуляция на несущую частоту');
plot(samples, carried, 'Color', [0.2 0.4 0.8]);
hold on;
plot(samples, y, 'r');
xlabel('Время t, с');
ylabel('Амплитуда');
title('Перенос сигнала на несущую (10f = 50)');
legend('Модулированный сигнал', 'Исходный информационный сигнал');
grid on;
```

### Синхронное детектирование и ФНЧ Баттерворта (lab2.m)
Демодуляция и выделение исходной информационной синусоиды:

```matlab
noised_carried = carried + noise;
NoCarry = noised_carried .* carry;

[b_butter, a_butter] = butter(4, 0.008, 'low');
FillNoCar = 2 * filtfilt(b_butter, a_butter, NoCarry);

figure('Name', 'Части 12-13: Демодуляция и фильтрация Баттерворта');
subplot(2, 1, 1);
plot(samples, NoCarry);
xlabel('Время t, с');
ylabel('Амплитуда');
title('Сигнал после перемножения с несущей (детектирование)');
grid on;

subplot(2, 1, 2);
plot(samples, FillNoCar);
xlabel('Время t, с');
ylabel('Амплитуда');
title('Восстановленный сигнал после ФНЧ Баттерворта');
grid on;

exportgraphics(gcf, 'graphic_lab2.jpg');
```
