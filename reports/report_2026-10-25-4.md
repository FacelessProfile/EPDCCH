## Подробное описание

### 1. Параметры канала (Вариант 8)
* Число лучей в канале: $N_B = 6$;
* Несущая частота: $f_0 = 2.1$ ГГц ($2.1 \cdot 10^9$ Гц);
* Полоса сигнала: $B = 11$ МГц ($11 \cdot 10^6$ Гц);
* Период дискретизации: $T_s = 1/B \approx 90.9$ нс;
* Скорость распространения радиоволн: $c = 3 \cdot 10^8$ м/с;
* Мощность шума: $N_0 = -30$ дБ.

### 2. Расчет характеристик лучей
Расстояния для 6 лучей генерируются случайным образом в диапазоне от 10 до 500 метров и сортируются по возрастанию. Первый луч $D_1 = \min(D)$ является прямым лучом (наименьшая задержка $\tau_1 = 0$).

Для каждого $i$-го луча:
* Задержка в дискретных отсчетах:
  $$\tau_i = \text{round}\left( \frac{D_i - D_1}{c \cdot T_s} \right)$$
* Коэффициент затухания амплитуды в свободном пространстве:
  $$G_i = \frac{c}{4\pi D_i f_0}$$

### 3. Формирование многолучевого сигнала и шума
Задержка отсчетов во временной области реализуется добавлением $\tau_i$ нулевых отсчетов в начало вектора:
$$S_i = [\underbrace{0, \dots, 0}_{\tau_i}, S_{tx}]$$
Суммарный многолучевой сигнал формируется сложением ослабленных лучей с усечением до исходной длины $L$:
$$S_{mpy} = \sum_{i=1}^{N_B} G_i S_i(1:L)$$

К сформированному сигналу добавляется комплексный белый шум:
$$S_{rx} = S_{mpy} + \mathbf{n}, \quad \mathbf{n} = \sqrt{\frac{10^{N_0/10}}{2}} (\mathbf{n}_I + j \mathbf{n}_Q)$$

Is channel applied? YES

## Технический пример (lab9.m)

Полный код скрипта [`labs/lab9/lab9.m`](../labs/lab9/lab9.m):

```matlab
function [rx_signal, Smpy, ch_info] = channel_multipath(tx_signal, Nb, N0_dB, f0, B)
    if nargin < 2, Nb = 6; end
    if nargin < 3, N0_dB = -30; end
    if nargin < 4, f0 = 2.1e9; end
    if nargin < 5, B = 11e6; end
    
    c = 3e8;
    Ts = 1 / B;
    L = length(tx_signal);
    
    D = sort(10 + (500 - 10) * rand(1, Nb));
    D1 = D(1);
    
    tau = round((D - D1) / (c * Ts));
    G = c ./ (4 * pi * D * f0);
    
    Smpy = zeros(1, L);
    for i = 1:Nb
        Si = [zeros(1, tau(i)), tx_signal];
        Smpy = Smpy + G(i) * Si(1:L);
    end
    
    noise_pwr = 10^(N0_dB / 10);
    noise = sqrt(noise_pwr / 2) * (randn(1, L) + 1j * randn(1, L));
    rx_signal = Smpy + noise;
    
    ch_info.D = D;
    ch_info.tau = tau;
    ch_info.G = G;
end


test_tx = randn(1, 120) + 1j * randn(1, 120);
[rx, smpy, ch] = channel_multipath(test_tx);
answers = ["NO", "YES"];
fprintf("Is channel applied? %s\n", answers((length(rx) == length(test_tx)) + 1));
```
