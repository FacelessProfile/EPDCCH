## Подробное описание

### 1. Назначение OFDM и опорных сигналов
Технология ортогонального частотного мультиплексирования (OFDM) преобразует широкополосный канал с частотно-селективными замираниями и сильной межсимвольной интерференцией (МСИ) в набор параллельных узкополосных подканалов с плоской АЧХ.

Для оценки искажений канала на приеме передатчик вставляет в спектр опорные сигналы (пилоты RS), значение которых заранее известно: $0.707 + 0.707j$. По варианту 8 пилоты размещаются с шагом $\Delta RS = 4$:
$$N_{RS} = \lfloor N_{QPSK} / \Delta RS \rfloor$$
Индексы пилотов: $1, 1+\Delta RS, 1+2\Delta RS, \dots$:
```matlab
rs_idx = 1 : Delta_RS : (1 + (N_rs - 1) * Delta_RS);
```
Все остальные поднесущие в активной полосе ($N_{active} = N_{QPSK} + N_{RS}$) заполняются информационными QPSK-символами.

### 2. Защитные нулевые интервалы
Слева и справа от активных поднесущих добавляются нули для предотвращения внеполосных излучений:
$$N_Z = \text{round}(C \cdot N_{active}), \quad C = 1/4$$
Полный частотный спектр имеет размерность:
$$N_{FFT} = N_{active} + 2N_Z$$

### 3. ОБПФ и циклический префикс
Временной сигнал формируется с помощью обратного преобразования Фурье:
```matlab
time_signal = ifft(spectrum);
```
Длительность циклического префикса составляет $N_{CP} = \text{round}(T_{CP} \cdot N_{FFT})$. Конец временного сигнала копируется в начало:
```matlab
cp = time_signal(end - N_cp + 1 : end);
tx_signal = [cp, time_signal];
```
Циклический префикс поглощает переходные процессы многолучевого распространения и превращает линейную свертку с импульсной характеристикой канала в круговую свертку.

## Технический пример (lab8.m)

Полный код скрипта [`labs/lab8/lab8.m`](../labs/lab8/lab8.m):

```matlab
function [tx_signal, params] = ofdm_mod(qpsk_syms, Delta_RS, T_cp, C)
    if nargin < 2, Delta_RS = 4; end
    if nargin < 3, T_cp = 1/16; end
    if nargin < 4, C = 1/4; end
    
    N_qpsk = length(qpsk_syms);
    N_rs = floor(N_qpsk / Delta_RS);
    
    rs_syms = repmat(0.707 + 0.707j, 1, N_rs);
    rs_idx = 1 : Delta_RS : (1 + (N_rs - 1) * Delta_RS);
    
    N_active = N_qpsk + N_rs;
    data_idx = setdiff(1:N_active, rs_idx);
    
    active_syms = zeros(1, N_active);
    active_syms(rs_idx) = rs_syms;
    active_syms(data_idx) = qpsk_syms;
    
    Nz = round(C * N_active);
    spectrum = [zeros(1, Nz), active_syms, zeros(1, Nz)];
    N_fft = length(spectrum);
    
    time_signal = ifft(spectrum);
    
    N_cp = round(T_cp * N_fft);
    cp = time_signal(end - N_cp + 1 : end);
    tx_signal = [cp, time_signal];
    
    params.Delta_RS = Delta_RS;
    params.T_cp = T_cp;
    params.C = C;
    params.N_qpsk = N_qpsk;
    params.N_rs = N_rs;
    params.N_active = N_active;
    params.Nz = Nz;
    params.N_fft = N_fft;
    params.N_cp = N_cp;
    params.rs_idx = rs_idx;
    params.data_idx = data_idx;
    params.rs_syms = rs_syms;
    params.spectrum_tx = spectrum;
end


test_qpsk = (1 - 2*randi([0, 1], 1, 60)) * 0.707 + 1j * (1 - 2*randi([0, 1], 1, 60)) * 0.707;
[tx, par] = ofdm_mod(test_qpsk);
answers = ["NO", "YES"];
fprintf("Is OFDM symbol generated? %s\n", answers((length(tx) == par.N_cp + par.N_fft) + 1));
```
