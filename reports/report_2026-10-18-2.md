## Подробное описание

### 1. Алфавит и параметры кодирования
Алфавит состоит ровно из 64 допустимых символов:
```matlab
alphabet = ['a':'z', 'A':'Z', '0':'9', ' ', '.'];
```
Поскольку мощность алфавита равна 64, разрядность кодового слова составляет $N_{bits} = \log_2(64) = 6$ бит. Разряды двоичного числа имеют веса степеней двойки: `[32, 16, 8, 4, 2, 1]`.

По Варианту 8 (строка 3, колонка 1 таблицы вариантов) длина сообщения составляет 45 символов. Общая длина закодированного сообщения в канале:
$$45 \text{ симв.} \times 6 \text{ бит} = 270 \text{ бит}$$

### 2. Алгоритм знакового кодера
Для каждого символа входного текстового сообщения:
1. Определяется порядковый индекс символа в алфавите от 0 до 63: `idx = find(alphabet == msg(i)) - 1`.
2. Индекс переводится в 6 двоичных бит путем деления на веса разрядов и взятия остатка:
   ```matlab
   char_bits = mod(floor(idx ./ [32, 16, 8, 4, 2, 1]), 2);
   ```
3. Сформированные биты последовательно добавляются в выходной вектор.

### 3. Алгоритм знакового декодера
При декодировании битовый массив считывается блоками по 6 бит:
1. Вычисляется номер символа в алфавите путем скалярного умножения шестерки бит на веса разрядов:
   ```matlab
   idx = sum(chunk .* [32, 16, 8, 4, 2, 1]);
   ```
2. По индексу извлекается символ: `alphabet(idx + 1)`.

### 4. Результаты работы
Скрипт протестирован на сообщении `'This is a test message for practice 1 var 8..'`:
* Исходная длина: 45 символов;
* Длина в битах: 270 бит;
* Восстановленное сообщение полностью идентично исходному (`Сообщения совпали: yes`).

## Технический пример (lab4.m)

Полный код скрипта [`labs/lab4/lab4.m`](../labs/lab4/lab4.m):

```matlab
function out = lab4(action, data)
    alphabet = ['a':'z', 'A':'Z', '0':'9', ' ', '.'];
    weights  = [32, 16, 8, 4, 2, 1];

    if nargin == 0
        % 45 symbols
        msg = 'This is a test message for practice 1 var 8..';
        
        tx_bits = lab4('encode', msg);
        rx_msg  = lab4('decode', tx_bits);
        
        fprintf('\n--- Знаковое кодирование ---\n');
        fprintf('Исходное сообщение: %s\n', msg);
        fprintf('Восстановленное:    %s\n', rx_msg);
        fprintf('Длина текста:       %d симв.\n', length(msg));
        fprintf('Длина в битах:      %d bit\n', length(tx_bits));
        
        if strcmp(msg, rx_msg)
            s = "yes";
        else
            s = "no";
        end
        fprintf('Сообщения совпали:  %s\n\n', s);
        return;
    end

    switch lower(action)
        case 'encode'
            msg = data;
            out = [];
            for i = 1:length(msg)
                idx = find(alphabet == msg(i)) - 1;
                char_bits = mod(floor(idx ./ weights), 2);
                out = [out, char_bits];
            end
            
        case 'decode'
            bits = data;
            out = '';
            for i = 1:6:length(bits)
                chunk = bits(i : i+5);
                idx = sum(chunk .* weights);
                out = [out, alphabet(idx + 1)];
            end
            
        otherwise
            error('Неизвестная команда. Используйте "encode" или "decode".');
    end
end
```
