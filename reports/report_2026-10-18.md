## Подробное описание

### 1. Параметры варианта
Для варианта 8 по таблице комбинаций определены параметры:
* Полоса пропускания: $B = 11$ МГц ($11 \cdot 10^6$ Гц);
* Несущая частота: $f = 2.1$ ГГц ($2.1 \cdot 10^9$ Гц);
* Мощность сигнала: $P = 1$ Вт;
* Спектральная плотность мощности шума: $N_0 = 10^{-15}$ Вт/Гц;
* Базовое расстояние: $d = 100$ м;
* Скорость света: $c = 3 \cdot 10^8$ м/с.

### 2. Формулы модели
Пропускная способность по теореме Шеннона:

$$C = B \log_2 \left( 1 + \frac{P_{rx}}{B N_0} \right)$$

Коэффициент ослабления в свободном пространстве:

$$\alpha = \frac{4\pi d f}{c}$$

Мощность сигнала на входе приемника с учетом ослабления:

$$P_{rx} = \frac{P}{\alpha^2}$$

### 3. Результаты расчетов
1. **$C(d)$:** При удалении приемника от 100 м до 5000 м пропускная способность резко снижается из-за квадратичного роста потерь мощности.
2. **$C(f)$:** На более низких частотах (0.21 ГГц) потери сигнала меньше, поэтому пропускная способность выше. С повышением частоты до 4.2 ГГц сигнал затухает сильнее.
3. **$C(B)$:** Расширение полосы пропускания увеличивает пропускную способность, но из-за одновременного роста мощности шума в полосе ($B \cdot N_0$) кривая замедляет рост и асимптотически приближается к пределу $\frac{P_{rx}}{N_0 \ln 2} \approx 18.64$ Мбит/с.

Итоговые графики трех зависимостей объединены и сохранены в файл `labs/lab3/graphic_lab3.jpg`.

## Технический пример (lab3.m)

Полный код скрипта:

```matlab
%% Расчет пропускной способности канала по Шеннону
clear all;
close all;

% Параметры
c = 3e8;
B = 11e6;       % 11 МГц
f = 2.1e9;      % 2.1 ГГц
d = 100;        % 100 м
P = 1;          % 1 Вт
N0 = 1e-15;     % Вт/Гц

%% Зависимость C(d) от расстояния
d_range = d:d:50*d;
alpha_d = (4 * pi * d_range * f) / c;
C_d = B * log2(1 + (P ./ alpha_d.^2) / (B * N0));

figure;
subplot(3, 1, 1);
plot(d_range, C_d / 1e6);
xlabel('Расстояние d, м');
ylabel('C, Мбит/с');
title('Зависимость C(d)');
grid on;

%% Зависимость C(f) от несущей частоты
f_range = 0.1*f:0.1*f:2*f;
alpha_f = (4 * pi * d * f_range) / c;
C_f = B * log2(1 + (P ./ alpha_f.^2) / (B * N0));

subplot(3, 1, 2);
plot(f_range / 1e9, C_f / 1e6);
xlabel('Частота f, ГГц');
ylabel('C, Мбит/с');
title('Зависимость C(f)');
grid on;

%% Зависимость C(B) от ширины полосы
B_range = 0.01*B:0.01*B:10*B;
alpha = (4 * pi * d * f) / c;
C_B = B_range .* log2(1 + (P / alpha^2) ./ (B_range * N0));

subplot(3, 1, 3);
plot(B_range / 1e6, C_B / 1e6);
xlabel('Полоса B, МГц');
ylabel('C, Мбит/с');
title('Зависимость C(B)');
grid on;

exportgraphics(gcf, 'graphic_lab3.jpg');
```
