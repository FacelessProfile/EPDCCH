## Подробное описание

### 1. Назначение перемежения
Сверточные коды и декодер Витерби эффективно исправляют изолированные случайные ошибки, однако при глубоких замираниях канала или импульсных помехах возникает пачка ошибок подряд (пакетная ошибка). В этом случае память кодера забивается неверными символами и декодер совершает серию ошибок.

Перемежитель решает эту проблему:
1. Перед отправкой в канал биты перемешиваются по псевдослучайному закону.
2. В канале пачка помех искажает группу соседних переданных бит.
3. На приеме деперемежитель возвращает биты на их исходные позиции, в результате чего пакетная ошибка распадается на множество удаленных друг от друга одиночных ошибок, которые легко исправляются декодером Витерби.

### 2. Алгоритм прямого перемежения
На вход поступает вектор бит длины $N$. Генерируется случайная перестановка индексов от 1 до $N$:
```matlab
seq = randperm(bits);
```
Каждый $i$-й бит исходного вектора помещается на позицию $seq(i)$:
```matlab
for i = 1:bits
    interleaved(seq(i)) = initial(i);
end
```

### 3. Алгоритм обратного перемежения
При обратном перемежении биты извлекаются с позиций, заданных тем же вектором $seq$:
```matlab
for i = 1:length(interleaved)
    initial(i) = interleaved(sequence(i));
end
```

### 4. Результаты работы

```text
Is rx == tx? YES
```
Длина вектора и значения бит сохраняются, порядок следования полностью восстанавливается.

## Технический пример (lab6.m)

Полный код скрипта [`labs/lab6/lab6.m`](../labs/lab6/lab6.m):

```matlab
function [initial,seq,interleaved] = interleaver(bits)
    initial = randi([0,1],1,bits);
    seq = randperm(bits);
    interleaved = zeros(1,bits);
    for i=1:bits
        interleaved(seq(i)) = initial(i);
    end
end

function [initial] = inv_interleaver(interleaved,sequence)
    for i=1:length(interleaved)
        initial(i) = interleaved(sequence(i));
    end
end


[init,seq,interleaved] = interleaver(15);
inverted = inv_interleaver(interleaved,seq);
answers = ["NO","YES"];
fprintf("Is rx == tx? %s\n", answers(all(inverted == init)+1));
```
