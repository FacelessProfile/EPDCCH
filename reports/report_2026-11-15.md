## Описание проделанной работы

Десятая неделя была посвящена переходу от базового одноточечного примера Blind Search PDCCH к полноценной статистической симуляции зависимости вероятности блоковой ошибки (BLER) от отношения сигнал/шум (SNR) в канале AWGN(`BlindSearch.m` в ветке `n.shalamov/pdcch_blind_search`):

* **Преобразование формата скрипта и актуализация конфигурации соты:** На базе примера `PDCCH_blind_search.mlx` был сформирован MATLAB скрипт `BlindSearch.m`
* **Параллельная симуляция Монте-Карло по сетке SNR:** Цепочка добавления шума, демодуляции (`ltePDCCHDecode`) и BlindSearch была обёрнута в параллельный цикл по сетке `SNRdB = -6:0.25:4` (41 точка). Для каждой точки SNR выполняется numFrames = 2000 испытаний (суммарно 82 000 кадров), что обеспечивает минимальное ненулевое разрешение по BLER на уровне $5 \cdot 10^{-4}$
* **Переход от фиксированной дисперсии к шкале SNR (дБ):** Вместо одиночного запуска с nVariance = 0.01 введён динамический пересчёт дисперсии комплексного шума на каждой итерации по формуле `nVariance = 1 / (10^(SNRdB(idx)/10))` (с учётом единичной средней мощности QPSK-символов на выходе ltePDCCH)
* **Фиксация порога полного отказа и визуализация результатов:** Добавлен расчёт верхней границы SNR, при которой вероятность ошибки равна единице с выводом значения в консоль. Построен итоговый график зависимости BLER(SNR).
* **Оформление изменений и подготовка Merge Request:** Изменения зафиксированы в коммите `fd9b043` в gitlab репозитории и оформлены в виде MR.

## Подробное описание

### Конфигурация физического канала и формирование передаваемого сигнала
В новом скрипте `BlindSearch.m` сохранена базовая конфигурация соты LTE (`NDLRB = 50`, `CyclicPrefix = 'Normal'`, `CFI = 3`, `Ng = 'Sixth'`, `CellRefP = 1`, `NCellID = 10`, `NSubframe = 0`, `DuplexMode = 'FDD'`). Для формирования полезной нагрузки используется сообщение `DCI Format 1A` (`Allocation.RIV = 26`), которое кодируется через lteDCIEncode с `C_RNTI = 100` и уровнем агрегации `PDCCHFormat = 0` (1 CCE = 36 ресурсных элементов = 72 бита после QPSK модуляции)
Закодированные биты размещаются в первом доступном кандидате UE-specific пространства поиска ltePDCCHSpace, после чего функцией `ltePDCCH` генерируются комплексные символы частотной области pdcchSymbols.

### Моделирование канала AWGN и параллельный расчёт BLER
Для оценки помехоустойчивости слепого декодирования на приёмной стороне реализован внешний параллельный цикл `parfor idx = 1:length(SNRdB)` по 41 значению отношения сигнал/шум от $-6$ до $+4$ дБ с шагом $0.25$ дБ:
* Дисперсия комплексного шума вычисляется как $N_0 = 10^{-\text{SNR}_{\text{дБ}}/10}$, а отсчёты шума формируются с независимыми действительной и мнимой частями дисперсией nVariance/2 каждая
* Внутренний цикл выполняет `numFrames = 2000` независимых испытаний для каждой точки SNR. На приёмной стороне вызываются `ltePDCCHDecode` и `ltePDCCHSearch`
* При пустом результате слепого поиска (`isempty(rxDCI)`) инкрементируется локальный счётчик ошибок `loc_counter`, после чего итоговая оценка BLER записывается в массив counter

### Определение порога отказа и построение графика
После завершения параллельного цикла выполняется поиск последнего индекса, для которого counter == 1 и в консоль выводится пороговое значение SNR в дБ. Для наглядного анализа кривой помехоустойчивости строится график plot(SNRdB, counter) с сеткой и стандартными подписями

## Технические примеры

### Параллельный цикл Монте-Карло по сетке SNR
Реализация расчёта nVariance, генерации комплЕксного шума и подсчёта BLER:

```matlab
%% Channel model (AWGN for now)
SNRdB = -6:0.25:4;
numFrames = 2000;
counter = zeros(1, length(SNRdB));

% parallel implementation to gain speed
parfor idx = 1:length(SNRdB)
    nVariance = 1 / (10^(SNRdB(idx)/10));
    loc_counter = 0;

    for i = 1:numFrames
        % WGN Noise in frequency domain
        noise = complex(randn(size(pdcchSymbols))*sqrt(nVariance/2), ...
                randn(size(pdcchSymbols))*sqrt(nVariance/2));  % Generate noise
        pdcchSymbolsNoisy = pdcchSymbols + noise;              % Add noise to PDCCH symbols

        %% Demodulator (PDCCH Decoding)
        recPdcchBits = ltePDCCHDecode(enbConfig, pdcchSymbolsNoisy);

        %% Decoder (Blind Decoding Using DCI Search)
        [rxDCI, rxDCIBits] = ltePDCCHSearch(enbConfig, ueConfig, recPdcchBits);
        if ~isempty(rxDCI)
            % Search succeeded
            decDCI = rxDCI{1};          % Decoded DCI information
            decDCIBits = rxDCIBits{1};  % Decoded DCI bits
        else
            loc_counter = loc_counter + 1;
            % Blind search failure
        end
    end

    counter(idx) = loc_counter / numFrames;
end
```

### Логирование порога отказа и визуализация
Определение верхней границы SNR полного отказа декодирования и вывод графика:

```matlab
last_one_idx = find(counter == 1, 1, 'last');
if ~isempty(last_one_idx)
    fprintf('BLER = 1 up to SNR = %.2f dB\n', SNRdB(last_one_idx));
end

% Graphical representation
figure;
plot(SNRdB, counter, 'b.-', 'LineWidth', 1.5, 'MarkerSize', 10);
grid on;
xlabel('SNR (dB)');
ylabel('BLER');
title('PDCCH BLER vs. SNR');
```

### Сводные параметры симуляции (`BlindSearch.m`)

| Параметр | Значение | Назначение |
| :--- | :--- | :--- |
| **Полоса и конфигурация соты** | `NDLRB = 50`, `CFI = 3`, `FDD` | Полоса 10 МГц, 3 OFDM-символа области управления |
| **Формат DCI и ресурсы** | `Format1A`, `PDCCHFormat = 0` (1 CCE) | Полезная нагрузка 27 бит + 16 бит CRC в 72 канальных битах |
| **Диапазон SNR** | `-6:0.25:4` дБ (41 точка) | Детальное покрытие переходной области кривой BLER |
| **Объём выборки** | `numFrames = 2000` на точку | Разрешение по BLER до $5 \cdot 10^{-4}$ (всего 82 000 кадров) |
| **Модель канала** | Частотный AWGN (`nVariance = 10^(-SNR/10)`) | Оценка базовой помехоустойчивости без замираний и OFDM-преобразования |
| **Распараллеливание** | `parfor` по сетке `SNRdB` | Ускорение расчёта Монте-Карло средствами Parallel Computing Toolbox |
