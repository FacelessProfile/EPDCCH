## Подробное описание

### 1. Таблица модуляции QPSK
В модуляторе входной битовый поток разбивается на пары бит $(b_0, b_1)$. Каждой паре ставится в соответствие комплексный символ $s = I + jQ$:

| Битовая пара $(b_0, b_1)$ | $I$ (Re) | $Q$ (Im) | Комплексный символ | Точка созвездия |
|:---:|:---:|:---:|:---:|:---:|
| **00** | $+0.707$ | $+0.707$ | $+0.707 + 0.707j$ | 1-й квадрант |
| **01** | $+0.707$ | $-0.707$ | $+0.707 - 0.707j$ | 4-й квадрант |
| **10** | $-0.707$ | $+0.707$ | $-0.707 + 0.707j$ | 2-й квадрант |
| **11** | $-0.707$ | $-0.707$ | $-0.707 - 0.707j$ | 3-й квадрант |

При нечетной длине входного массива бит в конец автоматически дописывается нулевой бит. Количество комплексных символов на выходе модулятора в 2 раза меньше числа входных бит.

### 2. Алгоритм QPSK модулятора
Координаты синфазной и квадратурной составляющих вычисляются по линейной формуле:
$$I = (1 - 2b_0) \cdot 0.707, \quad Q = (1 - 2b_1) \cdot 0.707$$
```matlab
for i = 1:N
    b0 = bits(2*i - 1);
    b1 = bits(2*i);
    I = (1 - 2*b0) * 0.707;
    Q = (1 - 2*b1) * 0.707;
    symbols(i) = I + 1j * Q;
end
```

### 3. Алгоритм QPSK демодулятора
Границами областей решений для созвездия являются координатные оси комплексной плоскости:
* Если $\text{Re}(s) \ge 0$, то $b_0 = 0$, иначе $b_0 = 1$.
* Если $\text{Im}(s) \ge 0$, то $b_1 = 0$, иначе $b_1 = 1$.

```matlab
for i = 1:N
    s = symbols(i);
    bits(2*i - 1) = double(real(s) < 0);
    bits(2*i)     = double(imag(s) < 0);
end
```

## Технический пример (lab7.m)

Полный код скрипта [`labs/lab7/lab7.m`](../labs/lab7/lab7.m):

```matlab
function [symbols, bits] = qpsk_mod(bits)
    if nargin < 1 || isempty(bits)
        bits = randi([0, 1], 1, 30);
    end
    if mod(length(bits), 2) ~= 0
        bits = [bits, 0];
    end
    N = length(bits) / 2;
    symbols = zeros(1, N);
    for i = 1:N
        b0 = bits(2*i - 1);
        b1 = bits(2*i);
        I = (1 - 2*b0) * 0.707;
        Q = (1 - 2*b1) * 0.707;
        symbols(i) = I + 1j * Q;
    end
end

function [bits] = qpsk_demod(symbols)
    N = length(symbols);
    bits = zeros(1, 2*N);
    for i = 1:N
        s = symbols(i);
        bits(2*i - 1) = double(real(s) < 0);
        bits(2*i)     = double(imag(s) < 0);
    end
end


[symbols, tx_bits] = qpsk_mod(randi([0, 1], 1, 30));
rx_bits = qpsk_demod(symbols);
answers = ["NO", "YES"];
fprintf("Is rx == tx? %s\n", answers(all(rx_bits == tx_bits) + 1));
```
