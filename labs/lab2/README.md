# Лабораторная работа 2: Представление сигналов, спектры и фильтрация

## Как это понимать с нуля
В этой лабораторной мы смотрим, как аналоговый сигнал живет в цифровой памяти, как увидеть его частотный спектр, что с ним делает шум и как вытащить сигнал обратно после модуляции на несущую.

---

## Вариант данных
* Частота информационного сигнала: $f = 5$ рад/с
* Мощность шума: $N = -10$ дБВт
* Длина окна фильтра скользящего среднего: $Len = 3$

---

## Разбор кода: логика и этапы

### 1. Как синус превращается в набор чисел
```matlab
SS = 0.1;
samples = 0:SS:2*pi;
y = sin(samples);
```
Компьютер не умеет хранить бесконечно непрерывную волну. Он берет отсчеты времени с шагом `SS = 0.1` секунды (дискретизация). Получается обычный массив чисел `y`, по которому строится один период синусоиды.

### 2. Формы отображения и спектр
Для сигнала $y = \sin(5 \cdot t)$:
```matlab
f = 5;
samples = 0:SS:2*pi;
y = sin(f * samples);
freqs = f * samples;
spectrum = abs(fft(y));
```
* Мы выводим сигнал тремя способами: `plot` (линия), `stem` (отсчеты точками), `stairs` (ступеньки, как на выходе ЦАП).
* `fft(y)` — быстрое преобразование Фурье. Оно раскладывает сигнал по синусам и косинусам и находит, какие частоты в нем сидят.
* Результат `fft` комплексный, поэтому мы берем `abs(fft(y))` — модуль комплексного числа, то есть амплитудный спектр. На графике виден четкий пик на частоте нашего сигнала.

### 3. Шум и скользящее среднее
```matlab
samples = 0:0.001:2*pi;
freqs = f * samples;
y = sin(f * samples);
noise = wgn(1, length(samples), -10);
signal = y + noise;
```
* Функция `wgn` генерирует белый гауссов шум. Он хаотично искажает отсчеты.
* Чтобы убрать быстрый шум, применяем фильтр скользящего среднего:
```matlab
Len = 3;
a = 1;
b = (1 / Len) * ones(1, Len);
filtered = filter(b, a, signal);
```
Каждый отсчет нового сигнала — это среднее арифметическое текущего и двух предыдущих отсчетов: $\frac{x[n] + x[n-1] + x[n-2]}{3}$. Мелкий шум сглаживается, хотя форма синусоиды становится чуть мягче.

### 4. Модуляция на несущую
Низкочастотный сигнал нельзя напрямую передавать через антенну в эфир (потребуется антенна огромных размеров). Поэтому его умножают на высокочастотную несущую (частота $10f = 50$):
```matlab
carry = sin(10 * f * samples);
carried = y .* carry;
```
По формулам тригонометрии перемножение во времени сдвигает спектр нашего синуса в область частоты 50 рад/с.

### 5. Детектирование и фильтр Баттерворта
К модулированному сигналу добавляется шум в канале: `noised_carried = carried + noise`.  
Как приемник достает низкочастотный сигнал обратно?
1. Снова умножаем принятую смесь на ту же самую несущую:
```matlab
NoCarry = noised_carried .* carry;
```
Математика перемножения синусов:
$$\sin(\Omega t) \sin(\omega_0 t) \cdot \sin(\omega_0 t) = \sin(\Omega t) \cdot \frac{1 - \cos(2\omega_0 t)}{2} = \frac{1}{2}\sin(\Omega t) - \frac{1}{2}\sin(\Omega t)\cos(2\omega_0 t)$$
У нас появился исходный низкочастотный синус (с множителем $1/2$) плюс паразитный высокочастотный хвост на удвоенной частоте.

2. Пропускаем сигнал через фильтр нижних частот (ФНЧ) Баттерворта:
```matlab
[b_butter, a_butter] = butter(4, 0.008, 'low');
FillNoCar = 2 * filtfilt(b_butter, a_butter, NoCarry);
```
* `butter(4, 0.008, 'low')` рассчитывает коэффициенты ФНЧ 4-го порядка.
* `filtfilt` прогоняет сигнал через фильтр вперед и назад, благодаря чему фазовая задержка полностью компенсируется (нулевой фазовый сдвиг).
* Множитель 2 возвращает амплитуду исходного синуса назад к единице. На графике восстанавливается чистый красивый синус.
