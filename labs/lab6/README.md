# Лабораторная работа 6 (Практика 3): Перемежение

## Как это понимать с нуля
В прошлой лабораторной мы увидели, как декодер Витерби идеально исправляет одиночные случайные ошибки. Но в реальном канале бывают помехи, которые портят сразу 5–10 бит подряд (пакетная ошибка). Если подряд испорчено много бит, декодер Витерби не сможет выбрать правильный путь на решетке и ошибется.

Чтобы спастись от пакетных ошибок, применяется **перемежение (Interleaving)**:
* Перед отправкой в эфир мы перемешиваем биты в псевдослучайном порядке.
* В канале помеха портит группу соседних бит.
* На приеме мы возвращаем биты на их исходные места (деперемежение).
* **Что происходит с ошибками:** группа сбитых бит оказывается разбросанной по всему тексту на сотни позиций друг от друга. Пакетная ошибка превращается в редкие одиночные ошибки, которые Витерби легко исправляет!

## Разбор кода: как устроен перемежитель

Код предельно простой и лаконичный:

```matlab
function [initial,seq,interleaved] = interleaver(bits)
    initial = randi([0,1],1,bits);
    seq = randperm(bits);
    interleaved = zeros(1,bits);
    for i=1:bits
        interleaved(seq(i)) = initial(i);
    end
end

function [initial] = inv_interleaver(interleaved,sequence)
    for i=1:length(interleaved)
        initial(i) = interleaved(sequence(i));
    end
end
```

### Разбор построчно на примере 4 бит
Пусть у нас есть исходный вектор:
`initial = [1, 0, 1, 1]`

Функция `randperm(4)` сгенерировала перестановку индексов:
`seq = [3, 1, 4, 2]`

1. **Прямое перемежение (`interleaver`):**
   * $i = 1$: кладем `initial(1)` (это 1) на позицию `seq(1) = 3` $\to$ `[?, ?, 1, ?]`
   * $i = 2$: кладем `initial(2)` (это 0) на позицию `seq(2) = 1` $\to$ `[0, ?, 1, ?]`
   * $i = 3$: кладем `initial(3)` (это 1) на позицию `seq(3) = 4` $\to$ `[0, ?, 1, 1]`
   * $i = 4$: кладем `initial(4)` (это 1) на позицию `seq(4) = 2` $\to$ `[0, 1, 1, 1]`
   * Перемешанный вектор: `interleaved = [0, 1, 1, 1]`.

2. **Обратное перемежение (`inv_interleaver`):**
   * Мы знаем ключ `sequence = [3, 1, 4, 2]`.
   * $i = 1$: берем элемент с позиции `sequence(1) = 3` из `interleaved` $\to$ получаем 1.
   * $i = 2$: берем элемент с позиции `sequence(2) = 1` из `interleaved` $\to$ получаем 0.
   * $i = 3$: берем элемент с позиции `sequence(3) = 4` из `interleaved` $\to$ получаем 1.
   * $i = 4$: берем элемент с позиции `sequence(4) = 2` из `interleaved` $\to$ получаем 1.
   * Восстановленный вектор: `[1, 0, 1, 1]` полностью совпал с `initial`!

### Проверка в консоли
```matlab
[init,seq,interleaved] = interleaver(15);
inverted = inv_interleaver(interleaved,seq);
answers = ["NO","YES"];
fprintf("Is rx == tx? %s\n", answers(all(inverted == init)+1));
```
При запуске выводится `Is rx == tx? YES`.
Длина вектора и значения не меняются — меняется только их расположение во времени.
