# Лабораторная работа 7 (Практика 4): QPSK модуляция

## Как это понимать с нуля
В этой лабораторной биты превращаются в точки сигнального созвездия — аналоговые комплексные радиосимволы.

В радиосвязи аналоговый сигнал представляется через синфазную ($I$) и квадратурную ($Q$) составляющие:
$$s(t) = I \cos(\omega_0 t) - Q \sin(\omega_0 t)$$
В комплексном виде это записывается как одно число:
$$s = I + jQ$$

При модуляции **QPSK (Quadrature Phase Shift Keying)** мы берем биты парами по 2 штуки ($b_0, b_1$) и сопоставляем каждой паре одну из 4 точек на комплексной плоскости.

---

## Таблица созвездия по методичке

| Пара бит ($b_0, b_1$) | $I$ (Re) | $Q$ (Im) | Комплексный символ | Квадрант плоскости |
|:---:|:---:|:---:|:---:|:---:|
| **00** | $+0.707$ | $+0.707$ | $+0.707 + 0.707j$ | 1-й (верхний правый) |
| **01** | $+0.707$ | $-0.707$ | $+0.707 - 0.707j$ | 4-й (нижний правый) |
| **10** | $-0.707$ | $+0.707$ | $-0.707 + 0.707j$ | 2-й (верхний левый) |
| **11** | $-0.707$ | $-0.707$ | $-0.707 - 0.707j$ | 3-й (нижний левый) |

> **Откуда число 0.707?**  
> Это $1/\sqrt{2} \approx 0.7071$. При таких координатах мощность каждого комплексного символа нормирована ровно на 1 Вт:
> $$P = I^2 + Q^2 = (0.707)^2 + (0.707)^2 = 0.5 + 0.5 = 1.0$$

## Разбор кода построчно

### 1. Модулятор (`qpsk_mod`)
```matlab
function [symbols, bits] = qpsk_mod(bits)
    if nargin < 1 || isempty(bits)
        bits = randi([0, 1], 1, 30);
    end
    if mod(length(bits), 2) ~= 0
        bits = [bits, 0];
    end
    N = length(bits) / 2;
    symbols = zeros(1, N);
    for i = 1:N
        b0 = bits(2*i - 1);
        b1 = bits(2*i);
        I = (1 - 2*b0) * 0.707;
        Q = (1 - 2*b1) * 0.707;
        symbols(i) = I + 1j * Q;
    end
end
```
1. Если на вход пришло нечетное число бит, в конец дописывается 0, чтобы биты делились на пары.
2. Для каждого шага цикла берется очередная пара: первый бит $b_0$ и второй бит $b_1$.
3. Формула `(1 - 2*b) * 0.707`:
   * Если бит равен 0: $(1 - 0) \cdot 0.707 = +0.707$.
   * Если бит равен 1: $(1 - 2) \cdot 0.707 = -0.707$.
4. Получаем комплексное число `I + 1j * Q`. Длина выходного вектора в 2 раза меньше числа бит.

### 2. Демодулятор (`qpsk_demod`)
На приеме из-за шума координаты точки слегка смещаются, но правильная область решения определяется просто по знакам координат:
```matlab
function [bits] = qpsk_demod(symbols)
    N = length(symbols);
    bits = zeros(1, 2*N);
    for i = 1:N
        s = symbols(i);
        bits(2*i - 1) = double(real(s) < 0);
        bits(2*i)     = double(imag(s) < 0);
    end
end
```
* Если вещественная часть $\text{Re}(s) \ge 0$, то `real(s) < 0` дает 0 (бит $b_0 = 0$). Иначе 1.
* Если мнимая часть $\text{Im}(s) \ge 0$, то `imag(s) < 0` дает 0 (бит $b_1 = 0$). Иначе 1.
* Никаких громоздких условий — две строчки восстанавливают оба бита.

### 3. Проверка
```matlab
[symbols, tx_bits] = qpsk_mod(randi([0, 1], 1, 30));
rx_bits = qpsk_demod(symbols);
answers = ["NO", "YES"];
fprintf("Is rx == tx? %s\n", answers(all(rx_bits == tx_bits) + 1));
```
При запуске выводится `Is rx == tx? YES`.
