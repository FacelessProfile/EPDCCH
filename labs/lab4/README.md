# Лабораторная работа 4 (Практика 1): Знаковое кодирование

## Как это понимать с нуля
В радиоэфир нельзя отправить буквы `'A'`, `'b'` или знак пробела. Вся цифровая аппаратура работает исключительно с битами — нулями и единицами.

Поэтому первый шаг любого цифрового передатчика — это **знаковый кодер**:
* Он берет текстовую строку и переводит каждую букву в последовательность бит.
* На приемной стороне стоит **знаковый декодер**, который собирает из этих бит точно такой же исходный текст.
* **Главное условие задания:** запрещено использовать встроенные функции Matlab вроде `dec2bin` и `typecast`. Все переводы из символов в биты мы пишем вручную на базовой арифметике.

## Вариант 8
* Длина сообщения: 45 символов.
* Тестовый текст: `'This is a test message for practice 1 var 8..'`
* Общее число бит: $45 \times 6 = 270$ бит.

---

## Разбор кода: как это работает построчно

### 1. Алфавит и разрядность
Мы используем фиксированный алфавит из 64 символов:
```matlab
alphabet = ['a':'z', 'A':'Z', '0':'9', ' ', '.'];
weights  = [32, 16, 8, 4, 2, 1];
```
* В алфавите 26 строчных букв + 26 заглавных + 10 цифр + пробел + точка = 64 символа.
* Так как $2^6 = 64$, каждый символ можно однозначно закодировать **ровно 6 битами**.
* Вектор `weights` — это веса двоичных разрядов: $2^5=32, 2^4=16, 2^3=8, 2^2=4, 2^1=2, 2^0=1$.

### 2. Кодер (текст в биты)
```matlab
case 'encode'
    msg = data;
    out = [];
    for i = 1:length(msg)
        idx = find(alphabet == msg(i)) - 1;
        char_bits = mod(floor(idx ./ weights), 2);
        out = [out, char_bits];
    end
```
1. `find(alphabet == msg(i)) - 1` находит позицию символа в алфавите (индекс от 0 до 63).
2. `floor(idx ./ weights)` делит этот индекс на каждый из весов `[32 16 8 4 2 1]`.
3. `mod(..., 2)` берет остаток от деления на 2, получая 0 или 1 в каждом разряде.

**Пример на пальцах:**  
Пусть буква имеет номер 41 в алфавите:
* Делим 41 на 32 $\to$ 1, остаток от деления 1 на 2 $\to$ **1**
* Делим 41 на 16 $\to$ 2, остаток 2 на 2 $\to$ **0**
* Делим 41 на 8 $\to$ 5, остаток 5 на 2 $\to$ **1**
* Делим 41 на 4 $\to$ 10, остаток 10 на 2 $\to$ **0**
* Делим 41 на 2 $\to$ 20, остаток 20 на 2 $\to$ **0**
* Делим 41 на 1 $\to$ 41, остаток 41 на 2 $\to$ **1**
Получились биты `[1 0 1 0 0 1]`. Проверяем: $32 + 8 + 1 = 41$. Всё сходится!

### 3. Декодер (биты обратно в текст)
```matlab
case 'decode'
    bits = data;
    out = '';
    for i = 1:6:length(bits)
        chunk = bits(i : i+5);
        idx = sum(chunk .* weights);
        out = [out, alphabet(idx + 1)];
    end
```
1. Берем очередную шестерку бит `chunk`.
2. Умножаем скалярно на веса `sum(chunk .* weights)` — сразу получаем десятичный индекс от 0 до 63.
3. Достаем символ из массива: `alphabet(idx + 1)` (в Matlab индексы массивов начинаются с 1, поэтому прибавляем единицу).

### 4. Тест в скрипте
Если запустить `lab4` без параметров, скрипт кодирует 45 символов варианта в 270 бит, декодирует обратно и проверяет совпадение:
```text
--- Знаковое кодирование ---
Исходное сообщение: This is a test message for practice 1 var 8..
Восстановленное:    This is a test message for practice 1 var 8..
Длина текста:       45 симв.
Длина в битах:      270 bit
Сообщения совпали:  yes
```
