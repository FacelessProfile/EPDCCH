# Лабораторная работа 1: Введение в Matlab/Octave

## Как это понимать с нуля
Это самая первая вводная лаба, в которой мы учимся базовым вещам в Matlab: объявлять переменные, работать с матрицами, писать циклы и выводить графики. Здесь нет сложной радиотехники, только фундамент языка.

---

## Вариант данных
* `a = 24` (номер в списке)
* `b = 26` (число студентов в группе)

---

## Разбор кода: что делает каждая строчка

### 1. Константы и арифметика
```matlab
a = 24; b = 26;
c = b - a;
d = c.*b - a;
e = a + 1i*b;
h = d .* pow2(10,2);
g = a * pi;
```
* Переменная `c = 26 - 24 = 2`.
* В `d` мы считаем $2 \cdot 26 - 24 = 28$.
* Комплексное число `e = 24 + 26i`: в Matlab мнимую единицу лучше писать как `1i` или `1j`, чтобы не путать с переменной `i` из циклов.
* Функция `pow2(10, 2)` означает $10 \cdot 2^2 = 40$. Умножаем на 28 — получаем 1120.
* В конце сохраняем все переменные блока в файл `lab1_part1.mat` через `save()`.

### 2. Векторы
```matlab
load("lab1_part1.mat",'c','d');
N = c + 1;
f = zeros(1,N); g = zeros(1,N);
h = f + g;
j = h * d;
v = ones(N,1);
v(3)
```
* Достаем `c` и `d` из сохраненного файла.
* `N = 3`. Создаем два нулевых вектора-строки длины 3: `zeros(1, N)`.
* `v = ones(N, 1)` создает вектор-столбец из единиц размера $3 \times 1$.
* `v(3)` — берем 3-й элемент. В Matlab индексация идет с 1, а не с 0.

### 3. Матрицы и умножение
```matlab
A = zeros(3,3); B = ones(3,3);
C = A * B;
D = A .* B;
D(1,1)
D(:,2)
D(2,:)
```
* `C = A * B` — это классическое умножение матриц (строка на столбец).
* `D = A .* B` — это поэлементное умножение: перемножаются числа, стоящие на одинаковых позициях. Для поэлементных операций перед знаком ставится точка (`.*`, `./`, `.^`).
* `D(:, 2)` берет весь второй столбец (двоеточие заменяет все строки).
* `D(2, :)` берет всю вторую строку.

### 4. Циклы и условия
```matlab
cntr = 0;
for c = 1:10*a
    cntr = cntr + c;
end

cntr2 = 0;
for c = 1:10*a
    if mod(c,2) ~= 0
        cntr2 = cntr2 + c;
    end
end

cntr3 = 0;
x = 0;
while x < a
   cntr3 = cntr3 + x;
   x = x + 1;
end
```
* Первый `for` просто суммирует числа от 1 до 240.
* Второй `for` суммирует только нечетные числа: остаток от деления на 2 проверяется через `mod(c, 2) ~= 0`.
* `while` крутит счетчик до тех пор, пока `x` меньше 24.

### 5. Полезные встроенные функции
```matlab
A = randn(1,10);
[maxA, maxAind] = max(A); minA = min(A);
C = ones(1,10);
D = zeros(1,10);
```
* `randn(1, 10)` генерирует 10 случайных чисел с нормальным (гауссовым) распределением.
* `max(A)` может возвращать сразу две вещи: максимальное число и его индекс в массиве.

### 6. Построение графиков
```matlab
A = randn(1,100);
figure;
bar(1:100,A,'FaceColor',[0.2 0.7 0.2]);
hold on;
stem(1:100,A,'Color','blue');
hold on;
plot(1:100,A,'Color','red');
xlabel('ось х - отсчеты');
ylabel('ось у - амплитуда');
title('Случайный вектор');
legend('Гистограмма (bar)','Отсчеты (stem)','Линейный график (plot)');
xlim([1,90]);
ylim([min(A), max(A)]);
grid on;
exportgraphics(gcf,'graphic.jpg');
```
* Рисуем три разных представления одного вектора: столбики (`bar`), дискретные отсчеты (`stem`) и гладкую линию (`plot`).
* Чтобы один график не стирал предыдущий, между ними пишется `hold on`.
* Функция `exportgraphics` сохраняет получившуюся картинку в файл `graphic.jpg`.
