# Лабораторная работа 10 (Практика 7): Эквалайзирование и OFDM демодуляция

## Как это понимать с нуля
В прошлой лабораторной сигнал прошел через многолучевой канал с шумом. На вход приемника пришла каша: лучи сложились в разных фазах, амплитудный спектр изрезало провалами и пиками, а точки созвездия QPSK размазались в круглое облако.

Задача приемника — распутать этот сигнал и вытащить данные:
1. Отрезать циклический префикс и вернуть сигнал в частотную область через прямое ДПФ (`fft`).
2. По известным пилотам RS понять, **что канал сделал с амплитудой и фазой** на разных частотах (оценка АЧХ/ФЧХ канала).
3. **Эквалайзер:** поделить спектр на оценку канала и стянуть размытые точки созвездия обратно в четкие вершины квадрантов.

---

## Пошаговый разбор кода демодулятора (`ofdm_demod`)

Функция выполняет 6 последовательных шагов:

### 1. Удаление циклического префикса
```matlab
rx_no_cp = rx_signal(params.N_cp + 1 : params.N_cp + params.N_fft);
```
Многолучевые отзвуки наложились на начало символа — то есть на циклический префикс. Мы просто отрезаем первые $N_{CP}$ отсчетов и выбрасываем их. Оставшиеся $N_{FFT}$ отсчетов свободны от межсимвольной интерференции.

### 2. Прямое ДПФ (`fft`)
```matlab
rx_spec = fft(rx_no_cp);
```
Преобразуем временной сигнал обратно в частотную область поднесущих.

### 3. Удаление защитных нулей
```matlab
C = rx_spec(params.Nz + 1 : end - params.Nz);
```
Отрезаем краевые нулевые поднесущие слева и справа. В векторе $C$ остаются только активные поднесущие (пилоты и данные).

### 4. Оценка АЧХ канала по опорным пилотам
Мы знаем номера позиций пилотов `params.rs_idx` и знаем их исходное идеальное значение `params.rs_syms = 0.707 + 0.707j`:
```matlab
rs_rx = C(params.rs_idx);
H = rs_rx ./ params.rs_syms;
```
Если в канале сигнал умножился на передаточную функцию $H$, то на частотах пилотов значение $H$ находится тривиальным делением принятого отсчета на известный исходный:
$$H = \frac{R_{rx}}{R_{tx}}$$

### 5. Интерполяция АЧХ на весь спектр
Пилоты стоят с шагом 4. Чтобы узнать передаточную функцию канала на поднесущих с данными, которые находятся между пилотами, мы делаем линейную интерполяцию:
```matlab
H_eq = interp1(params.rs_idx, H, 1:length(C), 'linear', 'extrap');
```
Вектор $H_{eq}$ теперь описывает передаточную функцию канала для абсолютно каждой активной поднесущей.

### 6. Эквалайзирование (Zero-Forcing) и снятие данных
```matlab
C_eq = C ./ H_eq;
rx_qpsk = C_eq(params.data_idx);
```
* Мы делим принятый спектр на расчетную АЧХ канала: $C_{eq} = C ./ H_{eq}$.
* Все амплитудные провалы и фазовые набеги полностью компенсируются.
* Забираем готовые QPSK-символы с информационных индексов. Точки созвездия снова четко стоят в своих квадрантах.
