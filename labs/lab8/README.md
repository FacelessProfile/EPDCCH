# Лабораторная работа 8 (Практика 5): OFDM модуляция

## Как это понимать с нуля
В современных стандартах связи (Wi-Fi, 4G LTE, 5G NR) данные передают с помощью **OFDM (Orthogonal Frequency Division Multiplexing)**.

**В чем главная проблема эфира:**  
Если передавать данные сверхбыстрым потоком на одной несущей, символы получаются очень короткими во времени. Когда сигнал отражается от домов и асфальта, задержанные копии символов «наезжают» друг на друга. Возникает межсимвольная интерференция (МСИ), и сигнал невозможно разобрать.

**Идея OFDM:**  
Вместо одного сверхбыстрого потока мы делим полосу частот на сотни параллельных узких **поднесущих частот**. На каждой поднесущей данные передаются медленно, поэтому задержки эха становятся ничтожно малы по сравнению с длиной символа.

Задача этой работы — собрать спектр OFDM-символа в частотной области и перевести его во временной аналоговый сигнал.

---

## Вариант 8 (параметры блока)
* Шаг опорных поднесущих: $\Delta RS = 4$
* Относительный размер циклического префикса: $T_{CP} = 1/16$
* Параметр защитных нулей: $C = 1/4$

---

## Пошаговый разбор кода модулятора (`ofdm_mod`)

### 1. Расчет и размещение опорных пилотов (RS)
Опорные поднесущие (Reference Signals, пилоты) — это маяки с заранее известным значением ($0.707 + 0.707j$), которые вставляются в спектр с шагом $\Delta RS = 4$. Приемник заранее знает это число и по нему измерит искажения канала.
```matlab
N_qpsk = length(qpsk_syms);
N_rs = floor(N_qpsk / Delta_RS);
rs_syms = repmat(0.707 + 0.707j, 1, N_rs);
rs_idx = 1 : Delta_RS : (1 + (N_rs - 1) * Delta_RS);
```

### 2. Добавление данных
Все оставшиеся места в активном спектре занимают полезные QPSK-символы:
```matlab
N_active = N_qpsk + N_rs;
data_idx = setdiff(1:N_active, rs_idx);

active_syms = zeros(1, N_active);
active_syms(rs_idx) = rs_syms;
active_syms(data_idx) = qpsk_syms;
```

### 3. Добавление защитных нулей по краям
Чтобы спектр сигнала не вылезал за пределы выделенного канала и не создавал помех соседним станциям (внеполосное излучение), слева и справа от активных поднесущих добавляются нулевые поднесущие:
```matlab
Nz = round(C * N_active);
spectrum = [zeros(1, Nz), active_syms, zeros(1, Nz)];
N_fft = length(spectrum);
```

### 4. Обратное дискретное преобразование Фурье (ОБПФ / IFFT)
```matlab
time_signal = ifft(spectrum);
```
Строчка, которая превращает частотный спектр поднесущих во временной аналоговый радиосигнал.

### 5. Добавление циклического префикса (ЦП)
Чтобы эхо от предыдущего символа не накладывалось на начало текущего, мы берем кусочек из самого конца символа длительностью $T_{CP} = 1/16$ и приклеиваем его в начало:
```matlab
N_cp = round(T_cp * N_fft);
cp = time_signal(end - N_cp + 1 : end);
tx_signal = [cp, time_signal];
```
В эфире многолучевое эхо портит только префикс, а тело символа остается нетронутым. На приеме префикс просто отрезается. Кроме того, благодаря циклическому префиксу линейная свертка в канале превращается в круговую, что позволяет эквалайзировать канал простейшим поэлементным делением!

Длина итогового массива отсчетов: $L = N_{CP} + N_{FFT}$.
