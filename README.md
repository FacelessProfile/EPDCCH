# EPDCCH - Моделирование систем связи в Matlab

Репозиторий для исследования и имитационного моделирования телекоммуникационных сигналов, приемопередающих трактов и каналов физического уровня в среде Matlab и GNU Octave.

[English documentation](README.en.md)

## Лабораторные работы

### Лабораторная работа 1: Введение в Matlab/Octave (`labs/lab1/`)
* **Тема:** Базовый синтаксис, константы, комплексные числа, векторно-матричная алгебра, циклы for и while с условными переходами, статистические функции, экспорт графиков.
* **Параметры варианта:** a = 24 (номер в списке), b = 26 (размер группы).
* **Скрипт:** [`labs/lab1/lab1.m`](labs/lab1/lab1.m)
* **Запуск из терминала:**
  ```bash
  cd labs/lab1 && matlab -batch "run('lab1.m')"
  ```
* **Выходной артефакт:** [`labs/lab1/graphic.jpg`](labs/lab1/graphic.jpg)

### Лабораторная работа 2: Представление сигналов в модели (`labs/lab2/`)
* **Тема:** Моделирование гармонических колебаний, дискретизация, амплитудный спектр на основе БПФ (fft), моделирование канала с аддитивным белым гауссовым шумом (wgn), фильтр скользящего среднего, модуляция на несущую частоту, синхронное детектирование и ФНЧ Баттерворта (butter, filtfilt).
* **Параметры варианта:** частота f = 5 рад/с, мощность шума N = -10 дБВт, окно фильтра Len = 3.
* **Скрипт:** [`labs/lab2/lab2.m`](labs/lab2/lab2.m)
* **Запуск из терминала:**
  ```bash
  cd labs/lab2 && matlab -batch "run('lab2.m')"
  ```
* **Выходной артефакт:** [`labs/lab2/graphic_lab2.jpg`](labs/lab2/graphic_lab2.jpg)

### Лабораторная работа 3: Модель расчета пропускной способности канала по Шеннону (`labs/lab3/`)
* **Тема:** Моделирование пропускной способности непрерывного канала связи точка-точка в условиях аддитивного белого гауссова шума (АБГШ) по теореме Шеннона — Хартли. Расчет коэффициента ослабления в свободном пространстве, исследование зависимостей $C(d)$ от расстояния ($1d \dots 50d$), $C(f)$ от несущей частоты ($0.1f \dots 2f$), $C(B)$ от полосы пропускания ($0.01B \dots 10B$) и асимптотического предела Шеннона при $B \to \infty$.
* **Параметры варианта 8:** полоса $B = 11$ МГц, несущая частота $f = 2.1$ ГГц, комбинация параметров (3, 3, 3, 2, 2, 2). Мощность передатчика $P = 1.0$ Вт, спектральная плотность шума $N_0 = 10^{-15}$ Вт/Гц, базовое расстояние $d = 100$ м.
* **Скрипт:** [`labs/lab3/lab3.m`](labs/lab3/lab3.m)
* **Запуск из терминала:**
  ```bash
  cd labs/lab3 && matlab -batch "run('lab3.m')"
  ```
* **Выходной артефакт:** [`labs/lab3/graphic_lab3.jpg`](labs/lab3/graphic_lab3.jpg)

* **Параметры варианта 8:** длина сообщения 45 символов (270 бит).

### Лабораторная работа 5 (Практика 2): Помехоустойчивое кодирование и декодер Витерби (`labs/lab5/`)

Интеграция с модулем знакового кодирования из лабораторной работы 4.

## Библиотека функций цифровой обработки сигналов (`dsp_lib/`)

Все алгоритмы из практических работ вынесены в чистые модульные функции в каталоге [`dsp_lib/`](dsp_lib/):
* `char_encode`, `char_decode` — знаковое кодирование/декодирование;
* `conv_encode`, `viterbi_decode` — помехоустойчивое сверточное кодирование и декодер Витерби;
* `interleave`, `inv_interleave` — прямое и обратное перемежение;
* `qpsk_mod`, `qpsk_demod` — QPSK модулятор и демодулятор;
* `ofdm_mod` — формирование OFDM-символа;
* `channel_multipath` — модель многолучевого канала с АБГШ;
* `ofdm_demod` — OFDM демодуляция с оценкой АЧХ и эквалайзером;
* `calc_ber` — расчет вероятности ошибок BER.

Запуск сквозного тестирования библиотеки:
```bash
matlab -batch "run('dsp_lib/test_dsp_lib.m')"
```
