# EPDCCH - Моделирование систем связи в Matlab

Репозиторий для исследования и имитационного моделирования телекоммуникационных сигналов, приемопередающих трактов и каналов физического уровня в среде Matlab и GNU Octave.

## Лабораторные работы

### Лабораторная работа 1: Введение в Matlab/Octave (`lab1/`)
* **Тема:** Базовый синтаксис, константы, комплексные числа, векторно-матричная алгебра, циклы for и while с условными переходами, статистические функции, экспорт графиков.
* **Параметры варианта:** a = 24 (номер в списке), b = 26 (размер группы).
* **Скрипт:** [`lab1/lab1.m`](lab1/lab1.m)
* **Запуск из терминала:**
  ```bash
  cd lab1 && matlab -batch "run('lab1.m')"
  ```
* **Выходной артефакт:** [`lab1/graphic.jpg`](lab1/graphic.jpg)

### Лабораторная работа 2: Представление сигналов в модели (`lab2/`)
* **Тема:** Моделирование гармонических колебаний, дискретизация, амплитудный спектр на основе БПФ (fft), моделирование канала с аддитивным белым гауссовым шумом (wgn), фильтр скользящего среднего, модуляция на несущую частоту, синхронное детектирование и ФНЧ Баттерворта (butter, filtfilt).
* **Параметры варианта:** частота f = 5 рад/с, мощность шума N = -10 дБВт, окно фильтра Len = 3.
* **Скрипт:** [`lab2/lab2.m`](lab2/lab2.m)
* **Запуск из терминала:**
  ```bash
  cd lab2 && matlab -batch "run('lab2.m')"
  ```
* **Выходной артефакт:** [`lab2/graphic_lab2.jpg`](lab2/graphic_lab2.jpg)

## Системные требования

* Matlab R2020b или новее (либо GNU Octave 6+)
* Пакеты расширений:
  * Signal Processing Toolbox (функции butter, filtfilt, filter)
  * Communications Toolbox (функция wgn)
